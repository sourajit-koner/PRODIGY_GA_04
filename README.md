# Task 04 - Image-to-Image Translation with cGAN

## Objective

Implement an image-to-image translation model using a Conditional Generative Adversarial Network (cGAN) called Pix2Pix.

## Model

The project uses:

- Pix2Pix
- U-Net Generator
- PatchGAN Discriminator
- Adversarial Loss
- L1 Reconstruction Loss

## Dataset

Facades paired image dataset.

## Technologies

- Python
- TensorFlow
- NumPy
- Matplotlib
- Google Colab

## Results

The model translates input architectural images into realistic building images.
